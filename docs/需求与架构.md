# bi-lite 需求与架构

## 0. 项目定位

本地、轻量的 BI 引擎，服务于财务与经营数据的模板填表报送。
输入是 Excel 与 YAML 接入规格；输出是按 YAML 报表规格填好的模板 Excel，图表为辅助产物。
新模板主要增加规格与映射，不增加一套执行逻辑或一张模板专属事实表。

## 1. 主要流程

```text
源 Excel → 原始着陆 raw → 接入规格展开 stg → DuckDB 事实表
                                               ↓
空白模板 + 报表规格 → 语义查询 → 结果矩阵 → 填充模板 / 图表
```

人通过 Web 或 CLI 操作；agent 通过 MCP 了解结构、编写规格。
所有入口复用接入、查询、编译与渲染引擎。

## 2. 范围

支持本地 Excel 接入、主数据对齐、口径计算、模板报送、必要的查询与图表。
第二版围绕指标声明与模板复用完善主链路。
不做复杂图表编辑器、定时调度、多租户或外部数仓对接。

## 3. 技术与工作区

开发按 `.node-version` 的 Node 基线原生运行 TypeScript，零前端框架；仅打包时转译 JavaScript，安装时不编译。
DuckDB 单文件存储；Parquet 归档；YAML 声明规格；xlsx-populate 填充模板。

`src/` 是引擎与三个入口；`models/` 是模型；`ingest/` 是接入规格；
`specs/` 是报表规格；`templates/` 是空白模板；`skills/` 是 agent 手册。
本地数据在 `data/`，报表输出在 `output/`，可重建示例在 `test/fixtures/`。

## 4. 数据模型

### 4.1 共享维度

主体、指标、期间是基础维度。主体与指标有当前属性与历史侧表，可显式按事实期取历史版本。
接入时先对齐主数据名称；格式差异归一，业务归并由人确认。

### 4.2 窄长事实表

财务事实粒度为：**期数 × 窗口起点 × 主体 × 指标 × 场景 × 币种**，度量为金额。
`fin_month` 为窗口终点，`period_from` 为起点，另保留导入批次。
指标增加通常增加维度成员和事实行，不增加金额列。
合同与业务线等运营事实按业务领域独立成表，共享适用维度。

### 4.3 窗口口径

- 单月：起点与终点同月。
- 本年累计：起点为当年一月，终点为报告月。
- 去年同期累计：落库保存去年窗口，查询按报告期平移对齐。
- 账面累计：起点按模型声明，源值实存，包含审计调整。
- 单月同比：语义层计算，使用单月及去年同期单月，不单独存行。

累计查询取指定期末或按月份分别展示。场景与币种需筛选、分组或显式换算。
默认实际/人民币来自事实表 `queryDefaults`，响应展示实际采用的范围。
换汇按事实窗口终点取月汇率，必须完整且唯一。

### 4.4 存储与生命周期

DuckDB 进程内单写者；Web 持库时 CLI 通过回环服务转交命名操作，未开 Web 时 CLI 取得工作区锁独立执行。
MCP 目前仍须单独占库。服务退出等待已接收操作完成，再关闭连接并释放运行状态与锁；崩溃后验证遗留进程状态再恢复。
批次归档从主库读取原生数据块，在独立内存实例写出并校验 Parquet；不重开库文件，主库始终禁用外部访问。
首次启动引导空库；已有结构的变化先 `plan`，再由人执行 `apply`。
本地数据、上传、归档、审计与报送输出不进入版本管理。

### 4.5 YAML 模型

`models/*.yml` 是业务结构的声明来源，解析为 IR 后生成 DDL、元数据与语义目录。
支持 dimension、fact、aggregate、bridge；维度和桥接可以声明固定成员。
聚合与桥接派生数据由 `rebuild` 重建；业务指标定义在 `metrics/`，源单位与符号转换由接入规格声明。

### 4.8 指标定义

`metrics/*.yml` 独立声明指标列表：`id`（稳定英文编号）、`name`、`unit`、`category`、
`direction`、`aliases` 与可选 `calculation`。公式只引用同文件或其他文件中已声明的指标编号，
支持四则运算、取余与括号；校验未知引用、重复编号/名称/别名及循环依赖。
每个指标的 `fact` 默认为 `fact_finance`，公式依赖必须来自同一事实表。

正常启动时在事务内同步指标主数据，编号通过既有别名映射关联物理 ID；首次接管存量指标按名称/别名匹配，
不重写事实外键，不删除未声明的旧指标。属性变更使用既有历史侧表；`effectiveFrom` 指定生效日，默认当天。
长运行服务在串行操作开始时重读并校验模型/指标；删除声明不删除主数据，历史别名保留。该同步与结构 `plan/apply` 分开。

基础指标按既有接入流程存储；派生指标不接收源金额、不物化为事实行。
查询和模板复用相同公式，先在相同期间、场景、币种和分组内聚合基础指标，再计算派生值；
派生指标只接受 `sum` 聚合，缺操作数或除零返回空值，汇率检查及 agent 支撑行阈值继续生效。
模板支持“指标行 × 口径列”、“公司行 × 指标列（固定口径）”与“公司行 × 口径列（固定指标）”的派生指标。
公式只在确定性本地引擎中执行，不接收 SQL 或任意代码。指标单位为标准单位，源值换算由接入规格显式声明。

### 4.6 导入批次

每次落库记录源文件与规格、事实行与批次关联。重复坐标默认拒绝；显式覆盖保留批次记录。
结构变化的应用与数据导入是不同动作。

### 4.7 raw 与 stg

原始文件/单元格着陆保留输入；标准化行保留规格、坐标与转换后的业务字段。
事实与标准化行在同一事务写入。重放从库内原始输入重新展开，与标准化行比较。

## 5. 规格与渲染

### 5.1 接入规格

声明源路径、目标事实表、工作表、锚点、行键、值列、口径与固定维度。
支持长表、宽表与网格；可以跳过派生列、排除合计行，声明日期格与空值处理方式。
流程：静态校验 → 试运行 → 主数据确认 → 事务落库与归档。
保存 YAML 不执行导入。

#### 5.1.1 单位与符号转换

`values.transforms` 声明源值转换规则：`fromUnit`、`toUnit`、可选 `sign: preserve / negate`、
`rounding: reject / half-up`。`metrics` 可列出稳定指标编号作为覆盖规则；省略时为区块默认规则，
最多一个默认规则，同一指标不得重复指定。未匹配规则的值保持原样，不根据表头或单元格格式猜单位。
支持元/千元/万元/亿元与比率/%的组内转换，相同单位可用于符号转换，不做币种换算。
目标单位必须匹配指标定义，未声明指标使用事实度量的单位。试运行展示规则、作用指标和单元格计数，不展示金额。

试运行、导入与重放共用展开时的转换函数；raw 保留源值，stg 和事实存转换后的值。
转换使用十进制定点运算，并按目标 DECIMAL 精度校验；默认拒绝额外小数，只有显式 `half-up` 才按绝对值四舍五入。
溢出、无法无损传入当前数值接口或单位不匹配时整批拒绝，空值保持既有 skip/null 行为。
每个新批次同事务保存接入规格、指标元数据和模型目录快照。默认重放使用批次快照与 raw，
不受之后修改 YAML、单位或别名影响；无快照的历史批次仍按传入规格重放，并在结果中标明。

### 5.2 报表规格

声明模板、目标事实表、参数、工作表与区块；每个区块描述行/列维度、排序、度量与范围。
指标与口径必须确定，参数实际参与过滤。区块可使用坐标或定义名称作为锚点。

#### 5.2.2 模板复用

指标身份、标准单位与公式放在 `metrics/`，模板规格只声明坐标、轴与取数范围。
`value.periodType` 为“公司行 × 指标列”固定一个已声明的实存口径，
`value.metric` 为“公司行 × 口径列”固定一个指标编号或名称；均可引用参数。
固定绑定不能与对应轴或过滤重复指定。累计口径仍须钉住报告期，场景/币种规则保持一致。
两种布局与原有“指标行 × 口径列”共用指标聚合函数，先分公司汇总依赖再计算比率。
模板金额/比率的数字格式分别保留；变换布局不复制指标公式、不新增业务事实表。

#### 5.2.1 派生表达式

规格可声明度量表达式，由本地表达式求值器计算。
业务口径与单位规则优先放入 YAML 声明，模板只负责布局。

### 5.3 渲染器

Excel 渲染从原模板打开，只填指定数据格，保留已有样式、数字格式、合并、公式、批注与图表。
图表渲染消费相同结果矩阵。精细排版由 Excel 等工具完成。

### 5.4 编译

规格经参数替换、维度与事实表解析，编译为 SQL，在本地 DuckDB 执行，返回结果矩阵。
可查询的表、维度与口径来自现有声明及注册表。

### 5.5 诊断

解析、Web 和 MCP 使用相同校验逻辑，返回位置、原因与修改建议。
模板推断生成草稿，每个轴说明来源与依据；推测项由人确认。

## 6. 数据边界

### 6.1 本机执行

源数据、金额、查询与模板填充都在本地引擎执行。引擎不调用 LLM。

### 6.2 人与 agent

Web/CLI 为本机用户返回精确查询值；MCP 只返回元数据、文本标签、数字格标记、坐标、形状与状态。
agent 无 SQL 入口，预览与报表工具不返回金额。受众由入口决定。
语义层的 agent 查询采用分档与明细支持阈值，但不作为 MCP 自由取数工具暴露。
agent 仅使用空白结构样表。结构读取、推断、agent 预览/渲染前，本地扫描所有工作表（含隐藏页）的单元格；
发现实存数值、缓存值、金额或百分比样式的数字文本，或解析/扫描失败时，拒绝并只返回安全提示，不返回文件标签或错误中的原始内容。
普通标签中的年份、期数等数字可保留；公式常量只作为存在标记。该检查不覆盖图片、批注或嵌入附件，不能撤回已上传文件可能造成的模型接触。

## 7. Agent 入口

内置规格助手的实施基线见 [方案与架构设计](agent-authoring/design.md)。
方案规定模板/数据分入口、业务文本对话、版本化人工确认及测试区 reset。
业务对话和版本化确认尚未实现；pi 已完成最小文本接入，以下描述为当前能力。
DeepSeek `deepseek-flash` 已用示例结构完成在线烟测。

### 7.0 内置助手准备层

`src/authoring/attachment.ts` 提供本地模板检查与结构投影，保存内容哈希、政策版本和附件任务。
`src/authoring/pi.ts` 提供最小文本会话适配：复用 pi 的供应商/模型接口，固定提案工具，
限制轮数与上下文，并支持取消；当前尚未接入 Web 对话。
`src/authoring/config.ts` 读取工作区外的显式供应商配置；`bilite authoring setup`
默认写入 DeepSeek 与 `deepseek-flash`，API key 单独保存为 0600 凭据文件，
`bilite authoring status` 只检查本地配置与密钥来源，`bilite authoring test --send`
用示例结构发一次真实请求。`src/authoring/context.ts`
构造仅含结构投影和用户文字的发送预览与实际请求输入。
`POST /api/authoring/template` 接收空白模板，`GET /api/authoring/task?id=...` 返回本地任务；
该接口尚未接入业务对话页面，不调用模型、不注册规格、不导入数据。
结构投影与本地附件记录分开：投影只包含允许的标签、布局、锚点和公式存在标记，
不依赖已注册的业务名称，不包含路径、YAML、原始公式或缓存值。
隐藏页参与全表检查，但首版投影省略；无法解析、含数据与结构超限分别返回受控状态。

测试区 reset 通过 CLI 使用，正式包包含实现但只处理显式标记的独立工作区；
Web 无 reset 入口；操作范围与命令见贡献指南。

### 7.1 工具

MCP 保留十二个兼容工具名；`dry_run_ingest`、`run_ingest` 仅返回拒绝状态，不读源文件、不执行导入。
操作字段与接线见 `skills/bi-lite-ingest/`，工具定义以 `src/mcp/tools.ts` 为准。

### 7.2 模板与自然语言

agent 用模板结构与业务意图写 YAML；模板推断给草稿，执行前由人确认范围与主数据。
规格是 agent 与确定性引擎的接口。
所有草稿先留在 `drafts/` 或结构提案中；agent 逐项说明语义、歧义与矛盾，等待用户明确确认当前版本后才可保存到生效规格目录。
静态校验通过、没有推测项或旧授权不替代确认。确认规格不等于授权 agent 导入；源数据试运行、主数据决定和正式导入由用户亲自在 Web 完成。
人工 CLI 保留导入能力；skill 禁止 agent 借 CLI、脚本、HTTP 或浏览器代操作绕过交接，这仍是 agent 行为约束，不宣称提供宿主级权限隔离。

## 8. Web 与 CLI

Web 提供导入向导、查询、模板与规格管理、预览与导出；只监听 `127.0.0.1`。
CLI 提供接入、渲染、查询、模型变更、重建、重放、验证、目录与 skill 导出。
全局命令由 `bin/bilite.mjs` 启动，依次按 `--workspace`、`BILITE_WORKSPACE`、当前目录向上的工作区标识定位，再加载业务模块；旧项目兼容根目录运行。
模型、指标、相对源路径、规格与输出均相对所选工作区；安装目录只提供引擎代码和初始化模型。
`bilite init [目录]` 建立标识和空业务目录；`--preset finance` 按需补入受控财务模型，不覆盖已有模型，不复制业务指标或数据库。
空工作区的网页提供添加财务基础模型入口。`bilite web [--port 4319] [--no-open]` 前台运行并默认打开浏览器。
查询页使用不含金额的模型状态、指标和事实月份目录区分未就绪原因，不以某个指标的查询结果判断是否有数据。
添加模型后更新初始化提示；导入成功或手动刷新会更新查询条件。导入页将详细规则折叠到帮助，上传文件作为本次执行源覆盖规格默认路径。
`bilite skill install` 显式复制手册到项目 `.agents/skills/bi-lite-ingest`；`--scope user` 选择用户 `CODEX_HOME/skills`。
副本记录引擎版本及模板文件哈希；默认拒绝覆盖，`--force` 只更新模板文件并保留其他文件，拒绝链接目录。不自动配置 MCP。

Web 报表参数从规格默认值生成，预览和导出传递同一组参数；修改参数或切换报表会使旧预览失效。
编译器返回不含金额的实际取数范围（指标、口径、报告期、过滤及默认场景/币种），供页面展示。
比率按指标单位或显式百分比格式显示。导入确认展示引擎实际展开的候选值格数，区分跳过空值与写入 NULL。

## 10. 关键约束

保留模板格式；累计与量纲范围明确；主数据歧义交人处理；派生数据可以重建。
开发验收只保留核心节点，避免扩展成参数穷举与开发过程记录。
