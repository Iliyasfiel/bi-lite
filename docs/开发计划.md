## 1. 第一版已完成

### 1.1 接入与着陆

Excel 长表/宽表/网格接入；试运行、主数据确认、事务导入、批次覆盖、raw/stg 与重放。

### 1.2 模型与存储

YAML 模型生成，结构 plan/apply，维度/事实/聚合/桥接与声明成员，Parquet 归档。

### 1.3 主数据

名称归一、别名与人工归并；主体/指标历史侧表和显式时点查询。

### 1.4 语义与报表

窗口口径、场景与币种默认范围、完整汇率换算；报表规格、模板推断、预览与保真导出。

### 1.5 三个入口

Web、CLI、MCP 共用引擎；agent 通过规格参与，金额在本地执行链路内。

### 当前支持边界

- 指标公式只支持同一事实表，先按范围聚合再计算；派生指标只接受 `sum`。
- 派生指标模板支持表中三种布局；固定口径须为模型声明的实存口径，不支持模板中的 calculator 口径。
- 接入转换支持金额单位、%/比率及反号，目标度量须为 DECIMAL；超精度默认拒绝，显式配置才舍入。
- 新批次保存接入快照；无快照的旧批次仍使用传入规格重放。
- Web 导出复用已预览的参数，数值按导出时的数据库状态读取，不冻结预览时的数据。

### 下一阶段

CLI 产品化方案见 [CLI升级计划](CLI升级计划.md)：分发、工作区、共享执行、网页入口与可选 skill 安装已实现。
`npm run package:check` 在临时目录安装真实 `.tgz`，验证网页、CLI 导入/出表/重放、skill 覆盖保护和服务恢复。当前实测 Windows / Node 24.18.0；最低 Node 和其他平台分发验收尚待完成。
手动流程测试使用 [18期经营测试](18期经营测试.md)，测试包可从仓库恢复，不依赖已有本地数据。

优先选一条真实报送流程，核对源单位、符号、指标定义和主数据映射，并逐格确认模板结果。
根据试用中出现的具体缺口决定是否扩展布局、参数编辑与单位规则，不默认扩大平台范围。
新增指标或转换语义前先更新架构说明，再实施。

## 3. 暂缓事项

DQ 体系、语义视图与更多治理能力暂缓，待主链路使用反馈确认必要性。
图表编辑器、调度、多租户和外部数仓仍不在范围内。

## 4. 开发方式

工作区保持少量示例与核心验收，不保存探针、测试输出、数据库备份或开发流水账。
每轮只验证重要节点，复用或替换用例，不随修改堆积测试。
当前 `npm run e2e` 使用隔离的临时工作区；手动试用可用 `npm run fixtures` 重建示例。
