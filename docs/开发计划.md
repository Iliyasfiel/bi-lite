# 开发状态与第二版计划

## 1. 第一版已完成

### 1.1 接入与着陆

Excel 长表/宽表/网格接入；试运行、主数据确认、事务导入、批次覆盖、raw/stg 与重放。

### 1.2 模型与存储

YAML 模型生成，结构 plan/apply，维度/事实/聚合/桥接与声明成员，Parquet 归档。

### 1.3 主数据

名称归一、别名与人工归并；主体/指标历史侧表和显式时点查询。

### 1.4 语义与报表

窗口口径、场景与币种默认范围、完整汇率换算；报表规格、模板推断、预览与保真导出。

### 1.5 三个入口

Web、CLI、MCP 共用引擎；agent 通过规格参与，金额在本地执行链路内。

## 2. 第二版优先顺序

| 顺序 | 功能 | 状态 / 交付目标 |
|---|---|---|
| 1 | YAML 指标定义 | 待开发：集中维护指标身份、单位、业务归类与计算定义 |
| 2 | 接入单位与符号转换 | 待开发：源单位转标准单位，保留转换定义与重放一致性 |
| 3 | 模板复用 | 待完善：同一指标定义服务多个模板，模板只声明布局与取数范围 |
| 4 | 主链路体验 | 按上述功能需要完善导入确认、范围展示与报表预览 |

每项以一条实际报送流程完成作为验收，优先复用现有引擎与规格。
指标定义与转换字段落地前先更新架构说明，再实施。

## 3. 暂缓事项

DQ 体系、语义视图与更多治理能力暂缓，待主链路使用反馈确认必要性。
图表编辑器、调度、多租户和外部数仓仍不在范围内。

## 4. 开发方式

工作区保持少量示例与核心验收，不保存探针、测试输出、数据库备份或开发流水账。
每轮只验证重要节点，复用或替换用例，不随修改堆积测试。
当前 `npm run e2e` 使用隔离的临时工作区；手动试用可用 `npm run fixtures` 重建示例。
