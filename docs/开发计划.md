# 开发状态与计划

当前阶段：本地 BI 主链路已完成第二版首批交付，内置 pi 规格助手已完成 SDK 适配收口。
供应商配置与受控上下文已接入服务层，并已用 DeepSeek `deepseek-flash` 完成示例结构在线烟测；
业务页面和版本确认尚未接入。真实业务验收继续使用
[18期经营测试](18期经营测试.md)，可重建示例通过不等于真实报送结果已验收。

## 1. 当前能力

| 范围 | 当前状态 |
|---|---|
| 接入与着陆 | Excel 长表/宽表/网格、试运行、主数据决定、事务导入、批次覆盖、raw/stg 与重放 |
| 模型与指标 | YAML 模型、结构 plan/apply、指标身份/单位/分类/别名、历史属性、聚合后公式 |
| 接入转换 | 金额单位、%/比率、反号与显式舍入；批次快照用于确定性重放 |
| 报表复用 | 指标 × 口径、公司 × 指标、公司 × 口径，共用语义计算及模板导出 |
| Web 主链路 | 空工作区引导、查询就绪状态、目录刷新、参数/取数范围、预览后导出 |
| 人工 CLI | 独立工作区、Web 持库时服务转交、查询/接入/出表及维护命令 |
| 外部 agent 止损 | 全工作簿空表检查；MCP 试运行/导入只返回拒绝；skill 要求确认并交接人工 Web |

限制：派生指标依赖必须来自同一事实表，只允许 sum 聚合；旧批次无快照时按传入规格重放。
Web 导出读取执行时的数据，不冻结预览时的数据库快照。

## 3. 下一步与交付顺序

每阶段先核对输入输出和完成条件，再实现、定向验收、更新状态；不以安装依赖或旧链路通过代替该阶段交付。
通用执行纪律见 [AGENTS.md](../AGENTS.md)，权限和数据边界见 [助手设计](agent-authoring/design.md)。

### 3.1 SDK 适配收口（已完成）

已锁定 `pi-agent-core`/`pi-ai` 1.3.0（MIT，Node >=22.19.0），使用 Agent、显式 Models 集合
和官方 `openai-completions` 协议适配器。首批只验收这一组合；当前环境在 Node 24.18.0、
darwin/arm64 通过，Windows/Linux 尚未针对 pi 重新验收。

默认预算为 120 秒超时、最多 1 次重试、重试等待上限 5 秒、输出上限 8192 token、
6 个模型轮次和 24000 字符提示上限；显式配置会覆盖默认值。

`test:pi` 已覆盖官方适配器经受控 fetch 发出文本与提案工具请求，验证输出上限、超时/重试配置、
前置取消不发请求、流中取消终止运行、未知工具不执行，以及轮数上限保留助手停止原因。
适配器只显式注册模型与工具，不读取项目/全局 skills、AGENTS.md、MCP 或扩展。

提案当前只有 kind/note，尚不是可注册规格；受控投影已接入服务层会话输入，Web 尚未调用。

### 3.2 上下文与供应商配置（当前）

前置：3.1 收口；上下文与配置可独立开发，首次真实请求须两者均通过。
交付：独立用户配置目录、明确供应商/端点/模型、环境变量或 API key；
复用 pi 的认证格式，不读取 `~/.pi/agent`，不执行配置中的命令，首版不开放 OAuth。
构造并校验模型 DTO，只选取允许的投影字段和用户文字；首个请求前提供可展开的发送预览。
对话文字不检测，页面常驻发送内容提示。

当前进展：已提供独立 JSON 配置、CLI 供应商配置入口、端点/模型校验和受控发送 DTO；
未知配置字段会拒绝，预览对象不含附件路径、文件名、文件字节、原始公式或缓存值。
密钥环境变量限定为 `BILITE_AUTHORING_*`，避免误把无关环境值发送给供应商。
`bilite authoring setup` 默认配置 DeepSeek 与 `deepseek-flash`，交互输入 API key，
密钥单独保存到用户配置目录的 `authoring-auth.json`（0600）；
`bilite authoring status` 只检查本地配置与密钥来源，不发网络请求。
`bilite authoring test` 先打印示例结构的发送预览，只有显式 `--send` 才发送；
源码入口 `test:pi:live` 保留同一套烟测。
DeepSeek `deepseek-flash` 的示例结构在线烟测已通过；Web 发送预览与真实请求接线仍待完成。

完成条件：测试在临时配置下运行；缺密钥、无效配置直接给出受控错误，不回退未知供应商；
日志与响应不回显密钥。用带额外本地管理字段的假附件验证出站请求无路径、文件字节、原始公式和缓存值；
模板改变须重检，超限停止且不静默截断。在线烟测仅使用用户明确选择的供应商和假结构；
未获该授权时保留在线待验状态，继续完成离线部分。

### 3.3 任务、草稿与版本确认

前置：受控上下文和固定工具边界通过。
交付：顺序消息、预期版本、取消与任务恢复；提案经现有解析/校验形成草稿、业务摘要和差异，
失败保留最近有效草稿。摘要从实际绑定生成，覆盖主体/合并范围、期间、指标、单位、场景、
币种、来源/聚合及排除规则；能力缺口阻止注册。
人工确认绑定草稿内容/版本、模板哈希、投影政策及模型/指标目录指纹，注册须幂等、原子写入。

完成条件：一条代表性修订流程验证过期修改被拒、依赖变化使确认失效、失败可恢复；
聊天中的肯定答复不触发注册，模型工具无法确认或导入。模型等待不占数据库事务或串行操作队列，
提交时重新核对依赖；崩溃恢复不只依赖聊天总结。

### 3.4 Web 业务闭环

前置：3.2 和 3.3 的服务层契约与边界通过；可提前做页面布局，发请求与注册须遵守前置条件。
交付：空白模板 → 发送预览 → 文字澄清 → 业务摘要/差异 → 确认规格 → 人工导入 → 本地预览导出。
提供明确的处理中、取消、失败与恢复状态；人工写接口具备本地认证、Origin/CSRF 和版本校验。

完成条件：在独立工作区跑通代表性假数据流程，并验证模型等待期间人工查询可用；
完成一条真实报送流程的人工业务验收，核对模板保真与实际取数口径。
CLI 保留确定性高级/维护操作，不新增 CLI 聊天。

### 3.5 迁移与发布

前置：Web 替代流程与真实业务验收通过。
交付：退役外部 agent/skill/MCP，移除源码开发 reset，清理入口、说明与发布资源。

完成条件：正式安装包无开发 reset，关闭助手仍能使用人工主链路；
按贡献指南复验实际安装包与目标平台，未验平台保持待验。

pi 供应商能力复用不代表所有端点均已验证；首批只验收一个明确服务组合。
模型不获得 shell、任意文件、SQL、HTTP、人工确认或数据导入工具。

## 4. 开发与验收入口

先按 [贡献指南](../CONTRIBUTING.md) 配置 `.node-version` 基线；工作区规则见 [AGENTS.md](../AGENTS.md)。
开发约定、当前架构和未来设计分别维护，避免把拟议能力写成现有保证。

| 变更 | 必要检查 |
|---|---|
| 环境 | `npm run doctor`，不打开业务库 |
| pi 适配与配置 | `npm run test:pi`，验证官方协议、预算、取消、工具、配置与发送 DTO |
| 在线烟测（手动） | `bilite authoring test` 查看预览，显式 `--send` 才发送；只用示例结构 |
| 接入、语义、模板、安全边界 | `npm run e2e`，在临时工作区使用假数据 |
| 源码开发 reset | `npm run test:development`，只在临时工作区清理 |
| CLI、Web 服务与分发 | `npm run package:check`，检查真实安装包且不包含开发 reset |
| 文档与低影响改动 | diff/链接等针对性检查 |

每轮只验证最重要的节点，不按参数排列或断言数量堆测试；验证结果写在任务/PR，文档不记录开发流水账。
当前构建只转译；构建成功不能替代运行验收。数据目录、个人配置、会话、日志和测试产物不进入 Git。

DQ 体系、图表编辑器、调度、多租户、外部数仓与自动合并抵销继续暂缓。
