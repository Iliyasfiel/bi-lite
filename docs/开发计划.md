### 当前支持边界

- agent 只处理通过本地空表检查的结构样表；含数据、疑似数值或检查失败时停止。草稿须解释语义并经用户确认后才注册，真实数据由用户在 Web 手动试运行和导入；MCP 的试运行/导入兼容入口已禁用。
- 空表检查与 skill 不能隔离通用 agent 的文件访问或撤回已上传内容，也不覆盖图片、批注与嵌入附件。
- 指标公式只支持同一事实表，先按范围聚合再计算；派生指标只接受 `sum`。
- 派生指标模板支持表中三种布局；固定口径须为模型声明的实存口径，不支持模板中的 calculator 口径。
- 接入转换支持金额单位、%/比率及反号，目标度量须为 DECIMAL；超精度默认拒绝，显式配置才舍入。
- 新批次保存接入快照；无快照的旧批次仍使用传入规格重放。
- Web 导出复用已预览的参数，数值按导出时的数据库状态读取，不冻结预览时的数据。

新增指标或转换语义前先更新架构说明，再实施。

## 4. 开发方式

工作区保持少量示例与核心验收，不保存探针、测试输出、数据库备份或开发流水账。
每轮只验证重要节点，复用或替换用例，不随修改堆积测试。
当前 `npm run e2e` 使用隔离的临时工作区；手动试用可用 `npm run fixtures` 重建示例。
新设备与协作工具说明统一维护在贡献指南，agent 必需约定留在 `AGENTS.md`；后续可把已验证的命令接入 CI，不提前承诺未验证的平台。
