# 18期经营测试源

本目录保存生成的假数据快照，不含真实业务数据。工作源由 `npm run fixtures:business` 复制到 `data/testing/`，本地数据库及导出不提交。

- 5个主体、6个指标、202501至202606共18期，主表540行。
- “经营数据”是接入源；“核验明细”保留资产、负债、净资产及净利润；“合并抵销”保留集团合并调整。
- 金额单位万元，两个财务比率使用百分数；累计、增长率及集团抵销说明见 `docs/18期经营测试.md`。
- 配套空白模板为 `templates/18期经营报送模板.xlsx`。

该快照用于手动业务流程验收；自动主链路验收继续使用独立的小型假数据与 `test/config/metrics`。
