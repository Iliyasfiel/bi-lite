接入规格与导入说明

接入规格是一份 YAML 文件，说明 Excel 的工作表、读取位置、指标、期间，以及单位和符号转换规则，可复用于相同版式的源文件。

页面会检查规格；试运行进一步读取源文件，展示取数范围、候选值格和待确认的公司或指标名称。核对后再确认导入。

上传的文件用于本次试运行和导入，优先于规格中的默认源路径；规格文本保持原样。未上传时使用规格中的源路径。

保存规格仅保存读取规则，不会导入数据。文件读取、计算和导入均在本机执行。
