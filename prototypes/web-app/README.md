# bi-lite Web 交互原型

Vue 3 + shadcn-vue + Tailwind CSS + Vite 的独立本地原型。接入规格配置器已重写为 Vue 页面，与其余页面共用组件和导航。
本目录依赖、锁文件、构建输出与根引擎隔离；不修改 `src/web/`，不连接业务数据库。

## 启动

使用项目 `.node-version` 对应 Node，在本目录执行：

```bash
npm ci
npm run dev
```

默认仅监听 `127.0.0.1:4327`；端口占用时报错，可显式执行 `npm run dev -- --port 4328`，不要终止其他服务。
生产构建为 `npm run build`；预览为 `npm run preview`。`npm run build:single` 另生成可用本地浏览器直接打开的 `dist/standalone.html`。
针对性检查为 `npm run check`。生成的 `dist/` 不提交，单文件在交付时按需重建。
依赖的具体版本由本目录 `package-lock.json` 固定，不使用 CDN 或外部字体。

## 体验路径

- 数据看板：按主体、期数、指标和口径查询内置样例，查看指标概览、最近 12 期走势、主体对比和源格明细；可保存常用查询条件或下载演示 CSV。多个主体分别展示、累计不跨期相加、缺数不补零。
- 日常报送：选择已发布规格 → 检查内置样例 → 处理未知主体、缺期数和重叠模拟 → 确认演示 → 查看操作记录。期间从行内读取，月筛选仅用于演示子集。
- 模板规格：打开“经营快报 · 配置练习”，为 H 列确认口径；查看完整坐标、圈区块、屏蔽、设置单元格例外、暂存、审阅并演示发布。
- 导出配置：从独立导出规格选择指标、主体自身、口径及公式策略；演示布局不是用户指定报送模板。调用页仅提供演示预览和 CSV。
- 本体配置：创建 profile 时确定维度，创建后只维护成员/别称与关系、换算元数据；已有引用的成员不可直接删除。创建 profile 会在明确确认后替换浏览器内的演示工作区。
- 依赖复核：“月度经营快报”显式引用单位换算示例，修改这条语义后仅该规格进入待复核且暂不可调用；无关联的导出规格继续可用。进入受影响规格人工复核并再次确认。

默认 profile 为主体、指标、期数、口径四维；金额按人民币，不再要求场景或币种绑定。外币导入换算尚待实现。
所有测试操作都可用侧栏“重置演示”恢复。四维原型使用新的浏览器存储键，旧六维原型草稿保留在原键中，不自动修改已有 profile 的维度结构。

## 范围

`src/demo/sample.js` 保存经营测试表的表头、标签和空值位置，全部数值已替换为演示值，可独立运行，不读取 `data/testing/`。
旧的独立接入页面已由本原型取代；本原型不处理任意 Excel 上传。
UI 来源检查不是正式 YAML 校验；日期窗口编译、单位转换、公式重算、业务取数、完整坐标冲突检测、生产版本/依赖追踪、文件发布与打包集成尚未接入。
看板使用显式演示列绑定（E 本年累计、F 去年同期累计、H 单月）和人民币金额约定，未接入正式查询或窗口编译；不把源表头自动视作已确认语义。
`node scripts/check-dashboard.mjs` 验证代表性坐标筛选、缺数、主体分列、币种及重复值边界；它不替代正式引擎验收。
自定义 profile 可体验创建与成员维护，但映射器仅演示预设维度；遇到不支持维度会阻止接入规格发布。
导出预览不能替代正式 Excel 填充和保真验收；预置或模拟记录不代表真实入库。

## 组件来源

`src/components/ui/` 由官方 `shadcn-vue@2.8.2` CLI 生成并保留源码，使用 Button、Badge、Input、Tabs、Dialog 等组件。
`components.json` 记录组件配置；生成工具不作为运行依赖。接入方式依据 [官方 Vite 文档](https://www.shadcn-vue.com/docs/installation/vite)。
本原型通过主题 token 和应用 CSS 统一视觉，Excel 网格及映射交互为业务组件。
